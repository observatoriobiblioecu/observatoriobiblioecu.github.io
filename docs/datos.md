# Datos abiertos

El Observatorio promueve el acceso abierto a la información generada.

Los datasets estarán disponibles en formatos reutilizables:

- CSV
- XLSX
- Visualizaciones interactivas
- Informes descargables

!!! abstract "Compromiso"
    Los datos publicados estarán acompañados de su metodología y fecha de actualización.
